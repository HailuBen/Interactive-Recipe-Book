


# Interactive-Recipe-Book

A simple web app to search, filter, and save your favourite recipes. Built with HTML, CSS, and JavaScript.

## Demonstration: 
[Watch the feature demo](https://github.com/user-attachments/assets/e9c76130-c3c8-441b-8b30-9a68d02a36e5)

## Features
- Search recipes by name or ingredient
- Filter by category (breakfast, lunch, dinner, dessert, etc.)
- Save recipes to Favourites (stored in localStorage)
