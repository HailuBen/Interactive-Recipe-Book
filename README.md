


# Interactive-Recipe-Book

A simple web app to search, filter, and save your favourite recipes. Built with HTML, CSS, and JavaScript.

## Presentation
Watch the project's presentation from the developers:

[![Watch the video](https://img.youtube.com/vi/E4Uf493gQjk/0.jpg)](https://www.youtube.com/watch?v=E4Uf493gQjk)

## Installation / Use
Simply click the website link to use this project. You may also download the project and open the index.html in the browser. For local use, VSCode and the extension "Live Server" are recommended.

## Demonstration: 
[Watch the feature demo](https://github.com/user-attachments/assets/e9c76130-c3c8-441b-8b30-9a68d02a36e5)

## Features
- Search recipes by name or ingredient
- Filter by category (breakfast, lunch, dinner, dessert, etc.)
- Save recipes to Favourites (stored in localStorage)
